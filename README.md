# 金正恩检测器

一个会整活的安卓应用：当无障碍服务检测到屏幕上出现「金正恩」时，立刻触发一套连招——红圈圈出目标、手机震动、屏幕展示将军图片、播放《你若三冬来》、弹出「将军的恩情还也换不够」通知。

> ⚠️ 仅供个人整活 / 学习使用，请勿未经允许安装到别人手机上。

##  功能

- 无障碍实时检测屏幕文字，命中关键词自动触发
- 红圈在屏幕上圈出目标文字
- 手机震动提醒
- 屏幕展示图片，右上角 ✕ 一键关闭（BGM 同时停止）
- 亮度拉满 + 播放内置音频（10 秒剪辑 × 1.2 倍速）
- 弹出通知：将军的恩情还也换不够

##  工作原理

1. AccessibilityService 读取当前窗口的文字节点
2. 命中「金正恩」等关键词后取到文字位置
3. 悬浮窗画红圈 + 展示图片（需要悬浮窗权限）
4. 并行执行：震动、亮度拉满、播放音频、弹通知

##  安装

仓库已附带成品 APK：`apk/KimDetector-v1.0.apk`（已签名，可直接安装）。

1. 用 Android Studio 打开工程，连接手机直接运行
2. 命令行打包：`gradlew.bat assembleRelease`，产物在 `app/build/outputs/apk/release/`
3. 安装后依次授权：修改系统设置、显示在其他应用上层、无障碍服务、通知

##  自定义

| 想改什么 | 改哪里 |
| --- | --- |
| 关键词 | `KimAccessibilityService.kt` 里的 `keywords` |
| 音频 | 替换 `app/src/main/assets/sandonglai.mp3` |
| 图片 | 替换 `app/src/main/assets/kim_image.jpg` |
| 通知文案 | `KimTrigger.kt` 里的 `postNotification` |

##  声明

- 无障碍服务只能识别屏幕上的**文字**，图片/视频里的人脸识别不了
